# DoubleBird's Home Assistant Add-ons

[中文说明](./README.zh-CN.md)

This repository contains Home Assistant add-ons maintained by DoubleBird.

## Installation

1. In Home Assistant, go to **Settings** → **Add-ons** → **Add-on Store**.
2. Open the menu (top-right) → **Repositories**.
3. Add this URL:

   `https://github.com/zcmk123/ha-addons`

4. Refresh the Add-on Store. The add-ons from this repository will appear.

## Available add-ons

- **[Chromium](./chromium/README.md)**: Web-accessible Chromium browser (Ingress supported).
