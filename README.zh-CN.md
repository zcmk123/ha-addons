# DoubleBird 的 Home Assistant 插件仓库

这个仓库包含由 DoubleBird 维护的 Home Assistant 加载项（Add-ons）。

## 安装方法

1. 在 Home Assistant 中进入：**设置** → **加载项** → **加载项商店**。
2. 右上角菜单 → **仓库**。
3. 添加仓库地址：

   `https://github.com/zcmk123/ha-addons`

4. 返回加载项商店并刷新，仓库中的加载项会出现在列表中。

## 可用加载项

- **[Chromium](./chromium/README.md)**：通过 Web 界面访问的 Chromium 浏览器（支持 Ingress）。
